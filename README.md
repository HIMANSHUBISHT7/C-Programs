# C-Programs

A collection of 167 beginner-to-intermediate C programs written while learning the language and data structures.

## What's inside
- **`1.c` – `17.c`: algorithms and data structures** – sequential and binary search; insertion, selection, bubble, merge, heap and counting sort; BFS and DFS; Kruskal's, Prim's and Dijkstra's graph algorithms; N-Queens, among others.
- **`G*.C` / `GG*.C`: fundamentals** – area/perimeter/volume formulas, odd/even and greatest-of-three, unit conversions, number series (tribonacci and others), pyramid patterns, telephone-bill calculation, matrix multiplication and linked-list operations.

## Build and run
```bash
gcc 1.c -o search && ./search
```
Each file is a standalone program with its own `main`.
